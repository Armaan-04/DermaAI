# DermaAI

Project files and documentation for DermaAI.

## Project structure

- `app.py` — application entry point
- `model.py` — model definition and inference helpers
- `config.py` — application configuration
- `utils/` — preprocessing and Grad-CAM utilities
- `models/` — pretrained model weights
- `data/` — sample test images, if permitted
- `assets/` — application images and icons
- `documentation/` — project documentation
